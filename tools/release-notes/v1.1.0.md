**ty\e Desktop for Windows**

- New app icon (the ty\e hexagon) in the installer, Start menu, taskbar and tray.
- The app now updates itself. It checks for a new version in the background and asks you to restart when the update is ready. You can also use **Help > Check for Updates**. The portable copy tells you when a new version is out.
- The installer is in English, and it creates the Desktop and Start menu shortcuts again. Version 1.0.x could not create them.
- Built on Electron 45 (was 32).

**Upgrading from 1.0.x:** download and run the installer once. From 1.1.0 on, updates arrive automatically.

**Unsigned build:** Windows SmartScreen may show "Windows protected your PC". Choose **More info**, then **Run anyway**.
